# Avenwood Estates concept site

A responsive, multi-page real estate website concept for a Nigerian property business.

## Pages

- `index.html` — homepage
- `properties.html` — searchable sample listings
- `property.html?id=1` — property detail and gallery
- `about.html` — brand story
- `contact.html` — enquiry form
- `dashboard.html` — local demo listing and enquiry workspace

## Run locally

Serve this folder with any static file server and open `index.html`. For example:

```powershell
python -m http.server 4173
```

The current demo uses browser local storage for listings, enquiries, and the WhatsApp setting. It has no shared database, authentication, or production lead delivery. Listing details, prices, photos, and brand copy are illustrative samples and must be replaced with verified client content before launch.
